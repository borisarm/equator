Política de privacidad

Última actualización: 9 de octubre de 2026

EquatorSolver es una aplicación para Windows publicada por Boris Armenta. Esta política explica qué hace la aplicación con tu información. En resumen: no recopila, guarda ni transmite ningún dato personal.

Información que recopila la aplicación

Ninguna. EquatorSolver no tiene cuentas de usuario, analíticas, publicidad ni telemetría propia. La aplicación no solicita acceso a internet y no se conecta a ningún servidor.

Información guardada en tu dispositivo

  • Hojas de trabajo: solo se guardan cuando tú decides guardarlas, en la ubicación que elijas.
  • Configuración: la aplicación recuerda el idioma de la interfaz en un pequeño archivo de tu perfil de usuario de Windows (%LOCALAPPDATA%\Equator\settings.json).
  • Diagnóstico: si la aplicación sufre un error interno, se escribe una descripción del error en un archivo de registro de tu carpeta temporal. Permanece en tu dispositivo y nunca se envía a ningún sitio.

Al desinstalar la aplicación se elimina su configuración. Las hojas de trabajo guardadas permanecen donde las guardaste.

Microsoft Store

La aplicación se distribuye a través de Microsoft Store. Microsoft puede recopilar información sobre descargas, compras y bloqueos según su propia declaración de privacidad, disponible en privacy.microsoft.com.

Menores

Como la aplicación no recopila datos personales, es adecuada para estudiantes de cualquier edad.

Cambios en esta política

Si una versión futura cambia el tratamiento de los datos, esta página se actualizará antes de publicar esa versión y la fecha de arriba cambiará.
