Ayuda con EquatorSolver

Escribe a support@equatorsol.es con dudas, sugerencias o problemas. Si un resultado parece incorrecto, incluye exactamente lo que escribiste: así podremos reproducirlo.

Primeros pasos

  • Escribe una expresión en una celda y pulsa Mayús+Intro para ejecutarla y pasar a la siguiente.
  • Cada resultado lleva un número; usa %3 para reutilizar el resultado del paso 3, o % para el anterior.
  • Asigna con := (a := 2, f(x) := x^2) y escribe ecuaciones con =.
  • La pestaña Guía de la derecha tiene ejemplos de cada tema; haz clic en uno para insertarlo.
  • help(integrate) describe cualquier comando.

Preguntas frecuentes

¿Cómo cambio el idioma?
Abre el menú … de la barra de herramientas y elige Idioma. Por defecto la aplicación usa el idioma de Windows.

¿Cómo compruebo una solución?
Escribe los pasos como una lista, un paso por cadena: check(["2x + 3 = 7", "2x = 4", "x = 2"]). La primera línea es el enunciado.

¿Puedo guardar mi trabajo?
Sí: las hojas de trabajo se guardan como archivos .eqnb y se abren de nuevo con doble clic.

¿Hay una prueba gratuita?
Sí: instálala desde Microsoft Store y todas las funciones están disponibles durante 7 días. Cuando termina la prueba, tus hojas de trabajo se siguen abriendo, editando y guardando, pero las celdas dejan de ejecutarse hasta que compres la aplicación. Microsoft Store gestiona la prueba y la compra; no hay que registrarse.

¿Necesita conexión a internet?
No. Todo se ejecuta en tu PC.

¿Qué requisitos tiene?
Windows 10 versión 2004 o posterior, o Windows 11, en x64 o ARM64.

Atajos de teclado

  • Mayús+Intro: ejecutar y pasar a la siguiente celda · Ctrl+Intro: ejecutar sin moverse · Alt+Intro: ejecutar y añadir una celda debajo
  • F5: ejecutar todas las celdas · Ctrl+Esc: detener el cálculo en curso
  • Ctrl+N / Ctrl+O / Ctrl+S: nuevo, abrir, guardar · Ctrl+Más / Ctrl+Menos: zoom
