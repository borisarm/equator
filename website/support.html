Support

Help with EquatorSolver

Write to support@equatorsol.es with questions, suggestions or problems. If a result looks wrong, include the exact input you typed: it lets us reproduce it.

Getting started

  • Type an expression in a cell and press Shift+Enter to run it and move to the next cell.
  • Each result gets a number; use %3 to reuse the result of step 3, or % for the previous one.
  • Assign with := (a := 2, f(x) := x^2) and write equations with =.
  • The Guide tab on the right has examples for every topic; click one to insert it.
  • help(integrate) describes any command.

Frequently asked questions

How do I change the language?
Open the … menu in the toolbar and choose Language. By default the app follows the Windows display language.

How do I check a worked solution?
Write the steps as a list, one step per string: check(["2x + 3 = 7", "2x = 4", "x = 2"]). The first line is the task.

Can I save my work?
Yes: worksheets are saved as .eqnb files and open again with a double click.

Does it need an internet connection?
No. Everything runs on your PC.

What are the requirements?
Windows 10 version 2004 or later, or Windows 11, on x64 or ARM64.

Keyboard shortcuts

  • Shift+Enter: run the cell and move to the next one · Ctrl+Enter: run and stay · Alt+Enter: run and add a cell below
  • F5: run all cells · Ctrl+Esc: stop the running calculation
  • Ctrl+N / Ctrl+O / Ctrl+S: new, open, save · Ctrl+Plus / Ctrl+Minus: zoom
