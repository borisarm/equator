# 应用商店信息 — 中文（简体）(zh-Hans)

## 产品名称
EquatorSolver

## 简短说明
精确数学的工作表：代数、微积分、方程、矩阵和绘图，并能逐步检查解题过程。离线可用，无需帐户。

## 说明
EquatorSolver 是一款适用于 Windows 的计算机代数系统。像在纸上一样书写数学——2x + 3 = 7、integrate(x^2 sin(x), x)、plot(sin(x), x, -5, 5)——即可得到精确且排版精美的答案。

每运行一行，就会成为工作表中带编号的一步。用 %n 引用任意结果，在下一步计算中继续使用，并把整个工作表保存为文件，以后再打开。

主要功能：
• 代数：展开、因式分解（包括多元多项式）、化简、部分分式、多项式除法、结式与判别式。
• 方程：多项式方程和方程组的精确解、不等式、含根式的方程；没有精确解时给出数值解。
• 微积分：导数、不定积分与定积分、极限、泰勒级数、求和与求积、梯度与雅可比矩阵。
• 微分方程：可分离变量方程、线性方程、任意阶常系数方程，支持初始条件。
• 线性代数：行列式、逆矩阵、特征值与特征向量、行化简、零空间与线性方程组，全部精确计算。
• 精度：可算到任意位数——N(pi, 1000)——还能从小数识别出精确常数。
• 假设：声明 x > 0 或 n 为整数，结果会随之化简。
• 绘图：可平移、缩放的交互式二维图像，参数曲线与极坐标曲线，散点图，以及可旋转的三维曲面。

检查解题过程：
每行写一个步骤，EquatorSolver 会逐步检查。它会指出出错的那一步，发现丢失的解或增根（例如两边平方之后），并告诉你最终答案是否正确。适合学生检查作业，也适合老师批改。

为日常使用而设计：
• 结果按教科书标准排版；任何结果都可复制为文本、LaTeX 或图像。
• 可搜索的函数面板、符号面板、变量面板，以及满是示例、一键插入的指南。
• 浅色和深色主题、缩放，以及覆盖所有操作的键盘快捷键。
• 提供 English、中文（简体）、हिन्दी、Español、Français、العربية（从右到左）、বাংলা 和 Português (Brasil) 界面。
• 完全在你的电脑上运行：无需联网，无需帐户，不收集任何数据。
