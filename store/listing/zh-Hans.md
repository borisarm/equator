## 说明
EquatorSolver 是一款适用于 Windows 的计算机代数系统。像在纸上一样书写数学——2x + 3 = 7、integrate(x^2 sin(x), x)、plot(sin(x), x, -5, 5)——即可得到精确且排版精美的答案。

私密、专注：EquatorSolver 完全离线工作。它从不联网，没有广告，无需帐户或登录，没有订阅，也不收集任何数据；你的工作表只保存在你的电脑上。无论在火车上、没有 Wi-Fi 的教室里，还是在限制上网的学校电脑上，都能照常使用。

每运行一行，就会成为工作表中带编号的一步。用 %n 引用任意结果，在下一步计算中继续使用，并把整个工作表保存为文件，以后再打开。

主要功能：
• 代数：展开、因式分解（包括多元多项式）、化简、部分分式、多项式除法、结式与判别式。
• 方程：多项式方程和方程组的精确解、不等式、含根式的方程；没有精确解时给出数值解。
• 微积分：导数、不定积分与定积分、极限、泰勒级数、求和与求积、梯度与雅可比矩阵。
• 微分方程：可分离变量方程、线性方程、任意阶常系数方程，支持初始条件。
• 线性代数：行列式、逆矩阵、特征值与特征向量、行化简、零空间与线性方程组，全部精确计算；LU、QR、Cholesky 分解和奇异值分解，对角化与 Jordan 标准形，矩阵指数，Gram–Schmidt 正交化，最小二乘与伪逆。
• 精度：可算到任意位数——N(pi, 1000)——还能从小数识别出精确常数。
• 假设：声明 x > 0 或 n 为整数，结果会随之化简。
• 绘图：可平移、缩放的交互式二维图像，参数曲线与极坐标曲线，散点图，以及可旋转的三维曲面。

检查解题过程：
每行写一个步骤，EquatorSolver 会逐步检查。它会指出出错的那一步，发现丢失的解或增根（例如两边平方之后），并告诉你最终答案是否正确。它还能检查手算的行化简：每一步写出变换后的矩阵，可附上所做的行变换（R2 → R2 − 3R1），它会说出每步的行变换，找出算错的行，并给出该变换应得的结果。适合学生检查作业，也适合老师批改。

## 此版本的新增功能
• 矩阵分解：lu、qr、cholesky 和 svd，以及奇异值和条件数。
• diagonalize 和 jordan、最小多项式，以及矩阵指数 expm(A, t)，可用于求解方程组 x' = A·x。
• Gram–Schmidt 正交化、列空间与行空间、投影、最小二乘 (lsq) 与伪逆 (pinv)。
• check() 现在可以检查手算的行化简：第一行写矩阵，之后每步写一个矩阵，可附上行变换（R2 → R2 − 3R1），每一步都会被验证。
• 含倍角的三角方程（如 cos(2t) = sin(t)）现在能精确求解。
• simplify 把复数的商写成 a + bi，并合并根式：15·⁴√125 / ⁴√5 = 15√5。
• 修复：恒成立的不等式（如 |x + 9| ≥ −6）现在给出全体实数。
• 已用开放代数教材中约 2500 道习题进行测试。
