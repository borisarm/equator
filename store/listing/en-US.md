# Store listing — English (en-US)

## Product name
EquatorSolver

## Short description
A worksheet for exact mathematics: algebra, calculus, equations, matrices and plots, with a step-by-step checker for worked solutions. Works offline, no account needed.

## Description
EquatorSolver is a computer algebra system for Windows. Type mathematics the way you write it — 2x + 3 = 7, integrate(x^2 sin(x), x), plot(sin(x), x, -5, 5) — and get exact, beautifully typeset answers.

Each line you run becomes a numbered step in your worksheet. Refer back to any result with %n, reuse it in the next calculation, and keep the whole worksheet as a file you can open again later.

What it can do:
• Algebra: expand, factor (including multivariate polynomials), simplify, partial fractions, polynomial division, resultants and discriminants.
• Equations: exact solutions of polynomial equations and systems, inequalities, equations with roots, and numeric solving when no exact answer exists.
• Calculus: derivatives, indefinite and definite integrals, limits, Taylor series, sums and products, gradients and Jacobians.
• Differential equations: separable and linear equations, constant-coefficient equations of any order, with initial conditions.
• Linear algebra: determinants, inverses, eigenvalues and eigenvectors, row reduction, null spaces and linear systems, all exact.
• Precision: evaluate to any number of digits — N(pi, 1000) — and recognise exact constants from decimals.
• Assumptions: tell it that x > 0 or that n is an integer, and results simplify accordingly.
• Plots: interactive 2D plots you can pan and zoom, parametric and polar curves, point plots and rotatable 3D surfaces.

Check worked solutions:
Write a solution one step per line and EquatorSolver checks every step. It points out the step where a mistake happens, notices lost or extra solutions (for example after squaring both sides) and tells you whether the final answer is right. Useful for students checking homework and for teachers checking work.

Made for daily use:
• Results are typeset like a textbook; copy any result as text, LaTeX or an image.
• A searchable function palette, a symbols palette, a variables panel and a guide full of examples you can insert with one click.
• Light and dark themes, zoom, and keyboard shortcuts for everything.
• Available in English, 中文（简体）, हिन्दी, Español, Français, العربية (right to left), বাংলা and Português (Brasil).
• Runs entirely on your PC: no internet connection, no account and no data collection.
